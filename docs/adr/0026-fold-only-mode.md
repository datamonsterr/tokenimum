# ADR 0026: Fold-only mode library (E6.4)

Date: 2026-10-29. Status: accepted.

## Context

E6.4 adds the `tkm_hosts::fold_only` library behind `--no-shims` (ADR 0001 item 1) and the
fold-only fallback (SPEC 6.12). It has four parts: an instructions-file block, a generated
skill, a run-wrapper library and mode selection. The CLI (`tkm init`, `tkm run`) is epic E7;
the idle-fold watcher is epic E4. Neither is part of this ADR.

## Decisions

`instructions_file(host)` returns the file or `None`. For `None`, `apply` and `remove_from`
return an `Ok` report with an `instructions` message and change nothing. Revisit agy when
its docs are readable.

### 2. Block format and splice rules

```
<!-- tokenimum:begin -->
<!-- Generated by tokenimum; do not edit this block by hand. -->
...body...
<!-- tokenimum:end -->
```

`splice` replaces the first complete block in place or appends one after a blank line. Bytes
outside the markers never change. `remove` undoes `splice` exactly for files ending in a
newline (it drops the added blank line and newline). A begin marker without an end marker is
not a block; `apply` refuses it with `InvalidPayload` rather than append a second block.

### 3. Safety rules (SPEC 6.12, ADR 0001 item 9)

- A git-tracked file is refused (`UnsafeTarget`) unless `allow_tracked`, which maps to config
  key `inject.instructions_file_tracked`. `remove_from` applies the same rule. The check is
  `writer::deny::refuse_tracked` (`git ls-files --error-unmatch`), reused, not copied.
- A symlink resolving outside the repository is refused by `writer::safe_target`.
- Writes use `writer::atomic_update` / `update_with_backup`: stage, compare, rename; one
  recompute if the file changed meanwhile, refusal on a second change.
- Re-applying the same body changes nothing.

### 4. Creation marker and `.git/info/exclude`

When tokenimum creates the file it writes an empty `<file>.tkm-bak` (ADR 0011 "did not
exist" marker) and appends `/<file>` and `/<file>.tkm-bak` once each to the path from
`git rev-parse --git-path info/exclude` (`writer::deny::update_exclude`, now taking the line
as a parameter). A file that already existed gets no marker and no exclude entry, so a
person's untracked file is not hidden. `remove_from` deletes the file and marker only when
the marker is empty and nothing but whitespace remains; exclude lines stay (harmless, and
another process may share them).

### 5. Skill directories

| Harness | Path | Evidence |
|---|---|---|
| Claude Code | user `<agent_home>/skills/tokenimum/SKILL.md`, project `.claude/skills/...` | https://code.claude.com/docs/en/skills |
| opencode | user `<agent_home>/skills/...` (`~/.config/opencode`), project `.opencode/skills/...` | https://opencode.ai/docs/skills/ |
| Kimi Code | user `<agent_home>/skills/...` (`~/.kimi/skills/`) | https://github.com/MoonshotAI/kimi-cli/blob/main/docs/en/customization/skills.md |
| Pi | project `.agents/skills/...` only | https://github.com/badlogic/pi-mono/blob/main/packages/coding-agent/docs/skills.md documents `~/.agents/skills/` and `.agents/skills/`, not a path under the Pi agent home |
| Codex, agy, Cursor, Codewhale | none | no skill directory verified |

`skill_path` returns `None` where nothing is verified; `install` and `uninstall` then return a
report-only result. The file starts with YAML frontmatter (`name: tokenimum`) and has the
marker `<!-- tokenimum-skill version=<v> host=<h>; ... -->` right after it. Install refuses an
existing `SKILL.md` without the marker; uninstall removes only a file with it.

### 6. Skill content

Only `tkm facts --brief` and `tkm why <event>`, both read-only. No claim about effects.

### 7. Run wrapper

`plan(host, program, args, session_id)` is pure and adds `TKM_SESSION_ID` and `TKM_HOST`
(`Host::as_str`). `execute(plan, clock, observer)` spawns with inherited stdio, calls
`observer.started` after a successful spawn and `observer.ended` after exit, and returns the
exit code (`None` after a signal). A failed spawn returns the I/O error and calls neither.
Time comes from a caller-supplied `Clock`; the library has no hidden clock. The observer's
`ended` is where E7 triggers the immediate fold.

### 8. Mode selection

`mode_for(host, shims)`: opencode and Pi are `Shim` with shims and `FoldOnly` without; every
other host is `Hooks`.
